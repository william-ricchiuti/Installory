Diagnosis

Why it doesn't give people a reason to download yet

  • The main question it answers is one few people ask. "Which packages do I have, across managers?" matters to you, but a beginner doesn't wake up wanting an inventory. Their questions are "what did my AI just do to my Mac?", "why is Python broken?", "did I leak a key?" and "can I delete this?". Only the last one is answered today.

  • The AI features are shallow, hidden, or possibly broken. An "agent CLI" is a row saying a config folder exists, with its folder date shown as the install date. Install history is off by default and needs a second folder grant. Skills show generic filler even though the app already reads their real descriptions. In the sandbox, home-relative scanning points at the app's container (see the red box below).

  • Beginners get dropped at the hard step. Cleanup ends with "copy this and run it in Terminal", with no walkthrough. The copy uses jargon throughout: payload, shadowed, provenance, baseline, cask, dangling symlink.

  • Nobody can find it. The subtitle "Understand your packages" contains no words people search for. There are two engineer-style screenshots, no ratings prompt, and the website still describes the 1.3-era app. The website repo has no git remote.

  • The foundation is strong and rare. It is sandboxed, offline, read-only and MIT, with invariants enforced in CI and about 880 tests. Every competing AI-tooling app runs commands, edits configs, or ships outside the App Store. That trust model supports a better pitch: the safe, read-only checkup for a Mac you code on with AI.

Possible P0: home folder resolves to the sandbox container.

Inside the App Sandbox, FileManager.default.homeDirectoryForCurrentUser returns ~/Library/Containers/<bundle-id>/Data. I checked this today with a sandboxed test bundle. Installory passes that value to the Agent CLI, editor-extension, Cargo, pipx, nvm, pyenv and uv lookups, and uses it to build the 22-item "Grant Recommended" menu (AppCoordinator.swift:1468, CanonicalDirectory.swift:22). Install history is unaffected because it uses the bookmark URL. One end-to-end check on the App Store build will confirm how much is affected. If confirmed, many users have never seen the app's AI features.
